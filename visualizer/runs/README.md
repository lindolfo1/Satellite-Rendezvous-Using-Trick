# Runs

Drop each Trick run here as a pair of files with the same stem:

    my_run.csv     the data-recording output
    my_run.json    the sidecar: utc_start_time, waypoint_range, tolerance

Both must be present. A `.json` without its `.csv`, or the reverse, is listed in
the sidebar as unavailable with the reason rather than being hidden.

Run data is not tracked by git -- only this folder is.
